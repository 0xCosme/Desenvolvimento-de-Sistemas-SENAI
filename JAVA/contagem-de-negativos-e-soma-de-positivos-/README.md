# Projeto: Busca em Vetor Ordenado

## Descrição

Este projeto é uma aplicação em Java que permite ao usuário inserir 15 números inteiros em um vetor, ordená-los e, em seguida, buscar um elemento específico dentro desse vetor.

O programa utiliza métodos da classe `Arrays` para ordenar os dados e realizar a busca de forma eficiente.

---

## Funcionalidades

* Leitura de 15 números inteiros fornecidos pelo usuário
* Ordenação automática do vetor em ordem crescente
* Exibição dos elementos ordenados
* Busca de um valor específico utilizando busca binária
* Retorno da posição do elemento ou mensagem caso não seja encontrado

---

## Tecnologias Utilizadas

* Java
* Classe `Scanner` para entrada de dados
* Classe `Arrays` para ordenação e busca
